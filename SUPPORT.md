# Support

For help using EsportLed Scoreboard:

- Open a GitHub Discussion for general questions.
- Open an Issue for reproducible bugs.
- Use the README setup instructions before reporting installation problems.

When reporting a bug, include:

- operating system and browser,
- web version or Electron/NDI app,
- OBS/Resolume/NDI version if relevant,
- sport selected,
- steps to reproduce,
- screenshots or a short screen recording when possible.

Commercial EsportLED project inquiries should go through:

https://esportled.com/contacta-con-nosotros/
