# Security Policy

## Supported Versions

Security reports are accepted for the current `main` branch.

## Reporting a Vulnerability

Please do not open public issues for security-sensitive reports.

Send a private report through GitHub's security advisory flow if available, or
contact the project owner through the official EsportLED contact channel:

https://esportled.com/contacta-con-nosotros/

Include:

- affected version or commit,
- steps to reproduce,
- impact,
- any suggested mitigation.
